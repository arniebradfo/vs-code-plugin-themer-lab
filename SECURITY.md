# Security policy

Themer Lab is experimental. Security fixes target the latest source and release.

Use [private vulnerability reporting](https://github.com/arniebradfo/vs-code-plugin-themer-lab/security/advisories/new)
for a suspected security issue. Do not post exploits, credentials, private code,
or complete settings files in a public issue.

For ordinary color, layout, preview, or recovery problems, use the
[bug report form](https://github.com/arniebradfo/vs-code-plugin-themer-lab/issues/new/choose).
Include the extension version, VS Code version, operating system, and a small,
redacted example.
