## [0.1.0] - 2026-11-22

Initial experimental release of Themer Lab: Live Theme Builder.

- Create coordinated Dark and Light themes from a few UI colors.
- Preview controls and code immediately, with optional live workbench preview.
- Generate automatic or anchored syntax palettes, or edit colors manually.
- Try 24 real-editor language samples.
- Apply to User or Workspace settings, cancel temporary previews, and recover
  interrupted theme-setting operations.
- Export a standalone VS Code color-theme JSON file.
- Original rainbow icon, Dark/Light screenshots, and MIT-licensed source.
- Local Windows, macOS, and Linux desktop support on VS Code 1.143.0 or later.
