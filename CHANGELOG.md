## [0.1.1] - 2026-11-07

Initial public source snapshot for the experimental 0.1.0 build. This is not a
Marketplace release.

- Coordinated Dark and Light themes from a small set of UI colors.
- Immediate component previews and optional live workbench preview.
- Automatic, anchored, and manual syntax palettes with real-editor samples.
- User and Workspace Apply, reversible preview, and interrupted-save recovery.
- Standalone theme JSON export.
- User documentation, isolated tests, CI review packages, and a gated
  Marketplace publishing workflow.
- Bot-assisted version/changelog PRs with explicit CI dispatch.
- Exact-source review candidates, automated VSIX inspection, checksums, and
  safe Marketplace/GitHub release reconciliation. Publishing remains disabled.
- Opt-in isolated native release acceptance and documented owner launch gates.
